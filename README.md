# 일단나와 (ILDANNAWA)

### 한국형 AI 맞춤 데이트·여가 코스 추천 서비스

**"어디 갈지 고민하는 시간은 줄이고, 함께하는 시간은 늘리자."**

일단나와는 사용자의 지역, 예산, 시간, 취향을 바탕으로 AI가 맞춤형 데이트 및 여가 코스를 생성하는 웹서비스입니다.

한국의 장소 탐색 환경에 맞춰 카카오맵의 실제 장소 데이터를 활용하고, 여러 장소를 하나의 일정으로 연결하여 사용자의 계획 부담을 줄이는 것을 목표로 합니다.

**공식 서비스:** https://www.ildannawa.com/

**KIROTHON 2026 저장소:** https://github.com/techtechchuchu/kirothon-team-031

**팀명:** 현디벨롭

**개발자:** 울산대학교 ICT융합학부 22학번 추재현

## 1. 문제 정의 (Problem)

### "이번 주말에 우리 어디 갈까?"

이 프로젝트는 개발자가 여자친구와 데이트 일정을 계획하면서 직접 경험한 작은 불편에서 시작되었습니다.

데이트를 준비할 때마다 맛집, 카페, 놀거리 등을 검색하고 장소별 후기와 위치를 비교해야 했습니다.

특히 한국에서는 카카오맵으로 장소를 검색하고 네이버 블로그에서 실제 방문 후기와 분위기를 확인하는 등 여러 플랫폼을 번갈아 사용하는 경우가 많습니다.

장소를 찾더라도 다음과 같은 불편함이 남습니다.

- 예산과 활동 시간에 맞는 장소를 직접 골라야 합니다.
- 장소 간 이동 거리와 방문 순서를 계산해야 합니다.
- 식사하기 적절하지 않은 장소가 추천될 수 있습니다.
- 장소 하나를 변경하면 전체 일정을 다시 조정해야 합니다.
- 비슷한 유형의 장소가 반복되어 일정이 단조로워질 수 있습니다.

서울 성수동처럼 다양한 맛집, 카페, 팝업스토어, 체험 공간이 밀집한 지역에서는 이러한 문제가 더욱 두드러집니다.

**일단나와는 여러 플랫폼을 오가며 정보를 찾고 일정을 조합하는 과정을 줄여, 누구나 쉽고 빠르게 여가 계획을 세울 수 있도록 개발한 서비스입니다.**

## 2. 핵심 기능 (Features)

### ① AI 기반 맞춤형 코스 생성

사용자의 조건을 분석하여 서로 다른 특징을 가진 코스 3개를 생성합니다.

**입력 조건**
- 지역 및 동행자
- 인원과 예산
- 시작 시간과 종료 시간
- 이동수단
- 선호 활동 및 제외 조건

AI가 실제 장소 후보를 바탕으로 일정 구성을 지원합니다.

### ② 한국형 장소 데이터 검색

카카오 Local API를 활용하여 실제 장소 정보를 검색합니다.

- 장소명 및 주소
- 위치 및 업종
- 전화번호
- 카카오맵 상세페이지

한국의 장소 탐색 환경을 고려하여 국내 장소 데이터를 기반으로 추천 결과를 구성합니다.

### ③ 장소 적합성 개선

서울 성수동의 실제 검색 결과에서 발견한 추천 오류를 개선했습니다.

- 베이커리와 간식점이 저녁 식사로 추천되는 문제 수정
- 어린이 놀이시설이 산책 장소로 추천되는 문제 수정
- 산책 장소가 한 코스에 중복되는 문제 개선
- 온라인 쇼핑몰 사업자가 놀거리로 추천되는 문제 차단
- 일반 상가가 복합쇼핑몰로 분류되어 추천되는 문제 개선

### ④ 식사 시간대 기반 일정 구성

식사 장소를 적절한 시간대에 배치하도록 규칙을 추가했습니다.

- 점심: 11:30~14:00
- 저녁: 17:30~20:30
- 분식 등 가벼운 식사는 시간대와 무관하게 허용
- 식사는 카페보다 앞에 배치
- 저녁 시간대가 포함되면 식사 장소 추가 시도

위 시간대는 서비스에서 설정한 기본 규칙입니다.

### ⑤ 조건을 유지하는 장소 변경

사용자는 추천된 장소 하나를 다른 장소로 변경할 수 있습니다.

이때 다음 조건을 유지합니다.

- 나머지 장소 및 방문 순서
- 1인 예산
- 종료 시간

조건을 충족하는 대체 후보가 없으면 무리하게 변경하지 않고 사용자에게 안내합니다.

### ⑥ 코스 저장 및 공유

- 추천 코스 비교
- 카페 제외, 예산 줄이기, 실내 위주 수정
- 브라우저 내 코스 저장
- 저장된 코스 조회 및 삭제
- 코스 공유

현재 저장 기능은 브라우저 기반이며 계정 간 동기화는 지원하지 않습니다.

## 3. 사용 시나리오 (Scenario)

### 서울 성수동 데이트 계획

**상황:** 토요일 오후, 여자친구와 성수동에서 데이트를 계획하는 대학생

| 항목 | 입력값 |
|---|---|
| 지역 | 서울 성수동 |
| 동행자 | 연인 |
| 인원 | 2명 |
| 예산 | 1인 50,000원 |
| 활동 시간 | 14:00~20:00 |
| 이동수단 | 도보 및 대중교통 |
| 선호 활동 | 맛집, 카페, 체험 |

**서비스 이용 과정**

1. 사용자가 일단나와에 접속합니다.
2. 지역, 예산, 시간, 취향 등의 조건을 입력합니다.
3. 카카오 장소 검색을 통해 실제 장소 후보를 수집합니다.
4. 업종, 중복 여부, 식사 시간대 등의 추천 규칙을 적용합니다.
5. AI가 사용자 조건을 고려하여 코스 3개를 생성합니다.
6. 사용자가 코스를 비교하고 원하는 장소를 변경합니다.
7. 최종 코스를 저장하거나 공유합니다.

*실제 추천 결과는 검색 데이터와 API 설정에 따라 달라질 수 있습니다.*

## 4. 기대 효과 (Impact)

### ① 장소 탐색 과정 간소화

여러 플랫폼을 오가며 장소를 검색하고 비교하는 과정을 줄입니다.

### ② 일정 계획 부담 감소

예산, 시간, 활동 유형을 고려한 코스 생성을 지원하여 사용자가 직접 일정을 조합하는 부담을 줄입니다.

### ③ 추천 결과의 실용성 개선

실제 검색 결과에서 확인한 장소 오분류 문제를 개선하여 부적절한 장소가 추천될 가능성을 줄입니다.

### ④ 다양한 일상 상황에 활용

데이트뿐 아니라 친구 모임, 가족 나들이, 주말 여가 활동 등에도 사용할 수 있습니다.

## 5. 차별점 (Differentiation)

### ① 한국의 장소 탐색 환경에 최적화

국내에서 널리 사용하는 카카오맵의 장소 데이터를 기반으로 한국 사용자에게 익숙한 여가 활동을 추천합니다.

### ② 장소 추천을 넘어 일정까지 생성

단순히 맛집이나 카페를 나열하는 것이 아니라 예산, 시간, 방문 순서를 고려하여 하나의 코스로 구성합니다.

### ③ 실제 장소 데이터에 기반한 추천 개선

서울 성수동의 실제 카카오 검색 결과에서 발견한 업종 오분류 문제를 수정했습니다.

### ④ 제약 조건을 유지하는 장소 변경

사용자가 장소 하나를 변경하더라도 나머지 일정과 예산 조건을 유지하도록 설계했습니다.

### ⑤ 사용자 선택권 제공

하나의 추천 결과만 제시하지 않고 성격이 다른 3개의 코스를 제공하여 사용자가 비교하고 선택할 수 있도록 합니다.

## 6. KIROTHON 2026 개발 및 개선 사항

### 개발 목표

서울 성수동의 실제 장소 검색 결과를 바탕으로 추천 정확도와 일정 구성 로직을 개선하고, 사용자 조건에 더욱 적합한 코스를 제공하는 것을 목표로 했습니다.

### 주요 개발 및 개선 내용

**1. 후보 필터링 로직 통합**

코스 생성과 장소 변경 기능에서 관리하던 추천 규칙을 `refineCandidates` 함수로 통합했습니다.

**2. 장소 오분류 개선**

베이커리, 어린이 놀이시설, 온라인 쇼핑몰 사업자 등이 부적절한 활동 유형으로 추천되는 문제를 수정했습니다.

**3. 추천 우선순위 개선**

프랜차이즈 카페와 패스트푸드를 무조건 제외하지 않고, 사용자의 요청과 대체 후보 수에 따라 우선순위를 조정했습니다.

**4. 식사 시간대 규칙 추가**

점심과 저녁 시간대에 적합한 식사 장소를 배치하도록 개선했습니다.

**5. 장소 변경 조건 강화**

예산과 종료 시간 등의 조건을 유지할 수 있는 경우에만 대체 장소를 추천하도록 변경했습니다.

**6. 비용 추정 오류 수정**

참치김밥이 고가 업종으로 분류되던 문제를 수정했습니다.

**7. 테스트 확대**

자동화 테스트를 15개에서 31개로 확대하여 장소 분류와 일정 제약 조건에 대한 검증을 강화했습니다.

**8. 실제 장소 검색 검증 도구 추가**

`scripts/seongsu-check.mts`를 통해 성수동의 실제 카카오 장소 검색 결과를 확인할 수 있도록 했습니다.

## 7. 설치 및 실행 (Installation)

### 개발 환경

- Node.js 22.13 이상
- Next.js
- TypeScript
- OpenAI API
- Kakao Local API
- OpenStreetMap / Photon

### 프로젝트 실행

```bash
npm ci
npm run dev
```

로컬 실행 주소: http://localhost:3000

### 환경변수 설정

프로젝트 루트에 `.env.local` 파일을 생성합니다.

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4.1-mini
PHOTON_URL=https://photon.komoot.io/api/
KAKAO_REST_API_KEY=
NEXT_PUBLIC_KAKAO_MAP_KEY=
```

API 키는 공개 저장소에 업로드하지 않습니다.

`OPENAI_API_KEY`와 `KAKAO_REST_API_KEY`는 서버 환경변수로 관리합니다.

`NEXT_PUBLIC_KAKAO_MAP_KEY`는 카카오맵 JavaScript SDK용 키이며, 카카오디벨로퍼스에 허용 도메인을 등록해야 합니다.

### Vercel 배포

Vercel에서 Next.js 프로젝트로 배포할 수 있습니다.

환경변수는 Vercel 프로젝트의 Settings → Environment Variables에 등록하고 재배포합니다.

## 9. 데이터 정확도 및 제한 사항

### 장소 정보

카카오 Local API는 장소명, 주소, 업종, 전화번호, 상세페이지 등의 정보를 제공합니다.

별점, 후기 수, 후기 본문, 실제 메뉴 가격은 해당 API에서 직접 제공하지 않습니다.

### 예산

표시되는 금액은 업종별 추정치이며 실제 메뉴 가격과 다를 수 있습니다.

### 이동시간

이동시간은 직선거리를 보정한 추정값입니다.

지도에 표시되는 점선은 방문 순서를 나타내며 실제 길찾기 경로가 아닙니다.

### 영업시간 및 예약

영업시간, 예약 가능 여부, 주차 정보는 자동으로 검증하지 않습니다.

### 저장 기능

저장된 코스는 사용자의 브라우저에 보관되며 다른 기기와 자동 동기화되지 않습니다.

### 향후 개선 사항

- 실제 방문 후기 데이터 활용 범위 확대
- 장소별 영업시간 확인
- 실제 이동 경로 기반 일정 계산
- 사용자 피드백을 활용한 추천 품질 개선
- 계정 기반 코스 저장 및 동기화
