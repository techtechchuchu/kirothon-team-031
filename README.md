### 이번 행사에서 변경한 것 (커밋 전 작업 내용)

주제: 서울 성수동 시연 결과의 장소 적합성 개선.

- 코스 생성과 `장소 바꾸기`가 같은 제외·우선순위 규칙(`refineCandidates`)을 쓰도록 통합했습니다. 이전에는 두 API 라우트에 규칙이 따로 복사되어 있었습니다.
- 실제 성수동 카카오 검색 결과(수정 전 배포)에서 확인된 오분류를 제외하도록 고쳤습니다.
  - 베이커리·간식점이 저녁 식사로 추천되던 문제
  - 어린이 놀이공간(`플레이파크`)이 산책으로 추천되던 문제
  - 한 코스에 산책이 두 곳 들어가던 문제
- 프랜차이즈 카페와 패스트푸드는 전역 금지가 아닙니다. 사용자가 원하거나 대체 후보가 3곳 미만이면 남기고, 대체 후보가 충분할 때만 뒤로 미룹니다.
- `장소 바꾸기`는 나머지 장소와 순서, 1인 예산, 종료 시간이 유지될 때만 결과를 돌려줍니다. 조건을 지키는 대체 후보가 없으면 거절합니다.
- 참치김밥이 고가 업종으로 분류되던 비용 추정 오류를 고쳤습니다.
- 샘플 코스 테스트 3개는 코드 오류가 아니라 테스트 좌표(울산)가 샘플 데이터(성수동)와 어긋난 것이었습니다. 예산·시간 제약은 그대로 두고 좌표만 바로잡았습니다.
- 온라인 판매 사업자(업종 `통신판매 > 인터넷쇼핑몰`)가 놀거리로 추천되던 문제를 막았습니다. 업종에 `쇼핑몰`이 들어 있으면 통과시키던 필터가 원인이었습니다.
- 놀거리에서 복합쇼핑몰·쇼핑센터 업종을 기본 후보에서 뺐습니다. 카카오는 일반 상가도 `복합쇼핑몰`로 분류해 방문할 만한 곳인지 업종만으로 알 수 없기 때문입니다. 백화점·방탈출·보드게임·볼링·체험 업종은 그대로입니다.
- `lib/curated-places.ts`: 팀이 직접 확인한 장소(예: 소품샵)만 넣는 목록입니다. 현재 비어 있습니다. 목록에 넣은 장소만 카드에 "팀 확인: …" 문구와 함께 표시됩니다. 후보 조회는 `scripts/find-places.mts`로 하며, 이 스크립트는 후보를 보여 줄 뿐 검증하지 않습니다.
- 식사 시간대 규칙을 넣었습니다. 일반 식사는 점심(11:30~14:00)·저녁(17:30~20:30)에만 시작하고, 분식 같은 가벼운 식사는 시간대와 무관하게 허용합니다. 시간대는 임의로 잡은 기본값입니다. 식사는 카페보다 앞에 배치하고, 저녁 시간대가 포함된 코스에 식사가 없으면 넣어 봅니다.
- 테스트를 15개에서 31개로 늘렸습니다. 새 테스트의 장소는 시험용 데이터이며 실제 카카오 응답이 아닙니다. 운영 화면에서 확인된 업종 문자열(베이커리, 온라인 쇼핑몰 등)은 회귀 테스트로 넣었습니다.
- `scripts/seongsu-check.mts`: 성수동 시연 조건을 실제 카카오 검색으로 확인하는 스크립트입니다. 키는 출력하지 않습니다.

### 이전부터 있던 것 (KIROTHON 이전 구현)

지역 검색과 서울 빠른 선택, 조건 입력과 코스 3개 제안, GPT 코스 구성, 카카오 장소 검색, OpenStreetMap 지도, 카카오맵 상세 링크, 장소 하나 교체, 코스 공유, 브라우저 내 저장, 서울 AI 데모 코스.

### 아직 작동하지 않거나 확인되지 않은 것

- 회원가입·소셜 로그인은 준비 중입니다. 저장한 코스는 이 기기의 브라우저에만 있으며 계정 간 동기화되지 않습니다.
- 별점, 후기 수, 영업시간은 카카오 장소 검색 API가 제공하지 않아 확인하지 않습니다.
- 표시 금액은 업종별 추정치이며 실제 메뉴 가격이 아닙니다. 예산에 정확히 맞는다고 보장하지 않습니다.
- 수정 후 코드의 실제 카카오 검색 전체 시연과 모바일 화면 시험은 아직 하지 않았습니다.
- 14~19시처럼 저녁 시간대가 끝에만 걸치는 코스는 저녁 식사 없이 일찍 끝날 수 있습니다.
- 남은 예산이 1만 원 미만이면 보충 로직이 장소를 더하지 않아, 장소가 한 곳뿐인 코스가 나올 수 있습니다.
- GPT 경로의 식사 배치는 실제 호출로 시험하지 않았습니다.

## 포함 기능

동행자·지역·인원·시간·예산·활동 입력, 지역 검색, OpenStreetMap 지도, 방문 순서 번호와 점선, 코스 비교, 카페 제외·예산 줄이기·실내 위주 수정, 브라우저 코스 저장·조회·삭제.

지도 점선은 방문 순서를 나타냅니다. 길찾기 경로가 아닙니다. 이동시간은 직선거리 보정치로 계산합니다. 가격은 카테고리별 예상 금액이고 영업시간·예약·주차 여부는 검증하지 않습니다. 실내 분류도 카테고리 기준입니다. 음식 취향과 자유 문장 해석은 GPT 연결 시 사용합니다. OSM 장소 데이터가 부족하면 결과가 적거나 생성이 어려울 수 있습니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm run dev
```

기본 주소는 http://localhost:3000 입니다. Vercel에서는 Next.js로 자동 감지해 배포합니다. 기존 Sites 관련 파일도 보관되어 있지만 Vercel 실행에는 사용하지 않습니다. `package.sites.json`은 이전 설정의 백업입니다.

GPT 설정: 로컬 `.env.local`에 아래 값을 넣거나, 배포 환경의 비밀 환경변수로 설정하세요. 키를 브라우저 코드에 넣지 마세요.

```dotenv
OPENAI_API_KEY=발급받은_키
OPENAI_MODEL=gpt-4.1-mini
PHOTON_URL=https://photon.komoot.io/api/
KAKAO_REST_API_KEY=
```

키는 전달된 소스에 포함되어 있지 않습니다. Vercel 프로젝트 Settings → Environment Variables에서 OPENAI_API_KEY를 Secret으로 등록하고 재배포하면 활성화됩니다. 플러그인은 필요하지 않습니다.

## 카카오 장소 검색과 정보의 정확도
Production 환경변수 KAKAO_REST_API_KEY를 등록하고 카카오디벨로퍼스에서 카카오맵 사용을 활성화하면 장소 검색에 카카오 Local API를 우선 사용합니다. 지도는 OpenStreetMap을 유지합니다. 등록된 값은 서버에서만 사용합니다.
공식 장소 검색 API는 상호·주소·전화·업종·상세페이지를 제공합니다. 별점, 후기 수, 리뷰 본문, 실제 메뉴 가격은 제공하지 않으므로 현재 별점·후기 수 정렬은 구현되지 않았습니다. 외부 링크는 사용자의 확인을 위한 검색·상세페이지 링크이며, 앱이 후기 내용을 수집·분석했다는 의미가 아닙니다.
표시 금액은 업종별 계획 기준이며 실제 가격으로 검증된 금액이 아닙니다. 이를 화면과 GPT 지시에 명시합니다. 별점·후기순 정렬에는 별도로 이용 가능한 신뢰할 수 있는 평점·후기 데이터가 필요합니다.
